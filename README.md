# 📚 HTML Practice Codes

Topic-wise organized HTML practice codes for learning web development fundamentals.

## 📁 Folder Structure

```
PRACTICE CODES/
├── 01_Basics/
│   ├── hello.html              - Basic HTML boilerplate
│   ├── text_formatting.html    - Headings, paragraphs, bold, italic, underline, sub/sup
│   ├── links_and_images.html   - Anchor tags, image tags, linking images
│   └── div_and_span.html       - Block vs inline elements
├── 02_Lists/
│   ├── ordered_list.html       - Ordered (numbered) lists with nesting
│   └── unordered_list.html     - Unordered (bullet) lists with nesting
├── 03_Tables/
│   └── tables.html             - Table with thead, tbody, colspan
├── 04_Forms/
│   ├── text_and_radio.html     - Text input, password, radio buttons
│   ├── checkboxes.html         - Checkbox inputs
│   └── dropdown.html           - Select/dropdown element
└── 05_Media/
    └── iframe_youtube.html     - Embedding YouTube videos with iframe
```

## 📝 Topics Covered
- HTML Document Structure (DOCTYPE, html, head, body)
- Text Formatting Tags (h1-h6, b, i, u, big, small, sub, sup, pre)
- Hyperlinks and Images (a, img)
- Block vs Inline Elements (div, span)
- Ordered and Unordered Lists (ol, ul, li)
- HTML Tables (table, thead, tbody, tr, th, td, colspan)
- Form Elements (form, input, label, select, option, button)
- Media Embedding (iframe)
