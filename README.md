# HTML Practice Codes

A topic-wise organized collection of foundational HTML practice exercises.

## 📁 Topic Structure

- **`01_Basics/`**: HTML boilerplate, text formatting tags (`h1-h6`, `b`, `i`, `u`, `sub`, `sup`), hyperlinks (`<a>`), images (`<img>`), and layout containers (`div`, `span`).
- **`02_Lists/`**: Ordered (`<ol>`) and unordered (`<ul>`) lists with multi-level nesting.
- **`03_Tables/`**: Tables (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`, `colspan`).
- **`04_Forms/`**: Interactive form controls including text inputs, passwords, radio buttons, checkboxes, and dropdown selectors (`<select>`).
- **`05_Media/`**: Media embedding and YouTube video integration via `<iframe>`.
